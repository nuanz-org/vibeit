# Taste

## Workflow & Communication
- Prefers brainstorming and discussion of ideas and architecture before any code is written; explicitly asks the assistant not to code during ideation phases. Confidence: 0.9
- When asking to review or assess the codebase ("check the architecture"), expects the assistant to actually go through the code — reading/exploring the repository directly — rather than relying on memory or doc search. Confidence: 0.7
- Writes in very fast, heavily typo-laden shorthand ("shoesu" = should you, "resurl" = result, "abotu" = about); expects the assistant to decode the intended meaning and answer directly without asking for clarification. Confidence: 0.8
- Wants clear, opinionated prioritization when discussing improvements — asks "what should I change first" and expects a recommended sequence with reasoning, not just a flat list of options. Confidence: 0.7
